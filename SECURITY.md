# Security and privacy

This daemon is always-on and microphone-facing. Treat deployment as local-only
infrastructure unless you have explicitly audited your Hermes provider, STT, and
TTS configuration.

- Wakeword inference runs locally through ONNX Runtime.
- Command audio is transcribed through the STT provider configured in Hermes.
- Responses are generated by the Hermes model/provider configured by the user.
- TTS uses the Hermes TTS provider configured by the user.
- Activation and command audio can be archived locally when enabled.

Do not publish activation archives or command WAVs unless the speakers consent.
Report security issues privately to the repository maintainer.
